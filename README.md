# winUtil

Набор небольших Python-программ и утилит для Windows, мультимедиа, работы с файлами, текстом, изображениями, сетью и автоматизации.

## Безопасность

Секреты и токены из исходных файлов удалены. Telegram-боты используют переменную окружения `TELEGRAM_BOT_TOKEN`. Файл `token.txt` исключён через `.gitignore`.

# English

A collection of small Python programs and utilities for Windows, multimedia, files, text, images, networking and automation.

## Security

Secrets and tokens were removed from the source code. Telegram bots use the `TELEGRAM_BOT_TOKEN` environment variable. `token.txt` is excluded by `.gitignore`.

## Programs

The project contains utilities for YouTube downloading, Whisper transcription, video/audio conversion, image processing, encryption, text editing, screenshots, networking, Telegram bots, file exchange, mathematical calculations and Windows automation. See the Russian section above for the per-file list.

## Notes

These are independent utility scripts collected in one repository. Some programs may require additional Python packages or external applications such as FFmpeg, LibreOffice or platform-specific Windows tools.
